## ctf-agent：技能选择中文化（L1+L3，复赛当天，未提交）

根因（实测确认）：`SkillLoader.select()` 用 `re.findall(r"[a-z0-9]+")` 从题面抽词，中文全丢；而 `index.json` 453 个 keywords **含中文 0 个**。所以"加 CJK 2-gram"这条路无效（实测命中 0 张卡）。中文 `category`（逆向/杂项/综合渗透）也不在 `_DOMAIN_ALIASES` 里，拿不到域分 +6。

三个后果：
1. 中文分类 + 中文题面 → 零技能（实测 `逆向/RC4`、`综合渗透/Shiro` 均空）；
2. 英文分类 + 中文题面 → 同域全平票 +6，排序退化名字典序，`misc` 域稳定发 `misc.llmagent.guard` + `misc.pt.zipfile`；
3. `web.intranet.relay` 的 `domain` 字段写作中文"渗透"，与归一后的 "web" 永远对不上。

改动（`ctf_ext/skills/index.json` +69 行、`loader.py` +75/-7）：
- `_DOMAIN_ALIASES` 加 23 条中文分类映射；`select()` 对**卡片 domain 也做归一**（修 relay）。
- 新增 `aliases` 字段（63 卡共 315 个中英专有名词），反向扫题面，命中 +7/卡（仅一次）。权重必须 >6，否则域兜底卡会挤掉跨域细节卡（实测 `杂项/流量分析` 会选中 `misc.unicode` 而非 `forensics.pcap.triage`）。
- 新增 `_alias_pattern()`：只对 ASCII 边缘加词边界，中文边缘不加 —— 否则 "Shiro反序列化" 里前面的 "o" 会让左断言失败；同时 `java` 不会命中 `javascript`。
- 新增 `default: true`（每域一张兜底卡）：同分优先，避免平票退化成字母序。6 张：crypto.encoding / reverse.elf.static / pwn.stack.recon / web.sqlinjection / forensics.archive_layers / misc.unicode。
- aliases 不进入 `index_text()`（目录 trigger 仍取 keywords[:3]），prompt 字节预算不变。

冒烟结果（原 → 现）：`misc/base64` llmagent.guard+pt.zipfile → crypto.encoding+unicode；`逆向/RC4` 空 → elf.static+antidebug；`综合渗透/Shiro` 空 → java.deser+sqlinjection；`杂项/流量分析` 曾回归 → pcap.triage。英文路径与四条旧断言均未退化。

注意：`index.json` 用行级插入脚本改的（`/tmp/patch_index.py`），首次写错把 domain/prerequisites 行吃掉过一次，靠 `git checkout` 恢复；脚本已加"字段完整性自检"，后续再改需保留。
