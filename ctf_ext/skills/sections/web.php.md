# web.php

## 触发
- 后端 PHP（.php 路由、报错特征）；题点常在弱比较、伪协议、过滤绕过、文件上传。

## 最小动作
1. tool=arena_http 读源码泄露（.bak、~ 备份、?source 参数），定位比较与过滤逻辑。
2. 弱比较：0e 前缀哈希、数组绕哈希比较、in_array/strpos 松散匹配用构造串绕过。
3. 伪协议：filter 流把源码 base64 读出、data 流执行；include/require 参数优先试。
4. 上传类：看 MIME/扩展名校验顺序，构造合法文件头加可解析后缀，配合路径参数落地。

## 命中判据
- 服务端返回内容含唯一 flag{...}。
- 负判据：过滤完整且无文件写入点；写 ruled_out 已试变体。

## 何时换路
- 源码是模板渲染转 web.ssti；SQL 拼接转 web.sqlinjection。

## 踩坑
- 新版 PHP 已移除部分特性（%00 截断等），按报错判版本再选路。
- 上传拿不到执行就先验证读文件通道可达性。

## 来源/边界
- 内部编写；不覆盖框架级 CVE 细节。
