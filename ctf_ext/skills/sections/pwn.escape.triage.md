# pwn.escape.triage

## 触发
- V8/浏览器引擎（版本号、d8）或 QEMU（设备模拟、逃逸字样）类题；预期收益低，重在识别与止损。

## 最小动作
1. tool=file_info 与题面确认引擎版本或模拟设备；tool=strings 找版本串与编译特征。
2. 对照已知 CVE 形态：类型混淆、JIT 边界、浮点数组越界；QEMU 走设备 MMIO 处理逻辑。
3. 评估预算：4 小时窗口内通常只做 PoC 级（确认崩溃/类型混淆），不做完整逃逸。
4. 确认可控崩溃即记录进展并换题，不重复投入。

## 命中判据
- 拿到可控崩溃（类型混淆/越界写）即记录为 PoC 进展。
- 负判据：版本无已知形态且无源码线索；写 ruled_out 及时止损。

## 何时换路
- 题面附调试 harness 或简化环境时，按普通栈/堆题处理。

## 踩坑
- 无版本号时不要盲试现成 payload，编译差异会让其全部失效。
- 此类题期望收益最低，时间盒最严。

## 来源/边界
- 内部编写；只做识别与止损，不含完整逃逸链。
