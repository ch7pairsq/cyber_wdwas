# web.ssrf

## 触发
- 服务端会请求用户提供的 URL（预览、webhook、导入、头像拉取），或题面提示存在内网服务。

## 最小动作
1. tool=arena_http 确认探测信号：错误信息/耗时/状态码差异可用作盲测。
2. tool=python_exec 生成探测清单：127.0.0.1、内网网段、file:// 协议、302 重定向到内网、等价 IP 写法。
3. 命中内网服务后按端口猜服务（admin 面板/缓存/元数据接口），构造受限 HTTP 请求打通读 flag。

## 命中判据
- 内网响应含唯一 flag{...}，或拿到下一步凭据。
- 负判据：协议与网段双重限制无法绕过；写 ruled_out 已试协议清单。

## 何时换路
- 回显进模板渲染转 web.ssti；入口是查询参数转 web.sqlinjection。

## 踩坑
- 302 跳转可绕前缀白名单；短链接/十进制 IP/0.0.0.0 等价写法逐个试。
- 响应体不回显时用布尔/耗时差异盲测，不要只看 200。

## 来源/边界
- 内部编写；不覆盖云元数据完整利用链。
