# pwn.pyjail

## 触发
- 远程/附件是受限 Python 解释器（黑名单 builtins、AST 或导入过滤、自定义小游戏外壳）。

## 最小动作
1. 枚举可达面：可用内置、可导入模块、字符串与反射入口；tool=python_exec 本地复现过滤逻辑。
2. 常见逃逸面逐试：继承链回溯 object 子类、装饰器与元类入口、格式化串读全局命名空间、异常对象属性。
3. 导入被禁时找已加载模块引用（模块快照、报错栈里的类）。
4. 拿到执行面后读文件取 flag，或走受限网段内的回显通道。

## 命中判据
- 执行结果含唯一 flag{...}。
- 负判据：白名单过滤且无可达反射面；写 ruled_out 已试入口。

## 何时换路
- 外壳是交互小游戏且逻辑在附件，先按 reverse 静态分析找后门分支。

## 踩坑
- 关键字过滤用拼接/编码绕过；先确认是关键字级还是 AST 级过滤再选方法。
- 交互轮次有限时把多步探查合并成单次提交。

## 来源/边界
- 内部编写；不覆盖 C 扩展层逃逸。
