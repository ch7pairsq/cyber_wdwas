# web.file_write

## 触发
- 已获文件写入点：上传接口、路径穿越写、模板/配置写入、zip slip/tar 符号链接构造包。

## 最小动作
1. 摸清约束：路径是否可控、扩展名与内容过滤、写入后的触发方式（访问/包含/重启）。
2. 落可解析位置：web 根下脚本扩展（双扩展/大小写）、配置文件（.htaccess/.user.ini）让任意扩展可解析、日志与会话文件配合包含。
3. 内容检测绕过：图片马（真实文件头+尾部代码）、短标签；tool=python_exec 生成变体与构造包（../ 条目名、符号链接）。
4. 触发验证：访问写入路径确认解析行为，读出唯一 flag{...}；只有写入无执行点时写探针并记 ruled_out。

## 命中判据
- 执行点返回唯一 flag{...}。
- 负判据：写入成功但无解析触发；写 ruled_out 列出已试位置与变体。

## 何时换路
- 上传为主入口转 web.upload；包含转 web.pathtraversal；PHP 特性转 web.php。

## 踩坑
- 先写无害探针确认"写哪能活"再上脚本；相对路径基准目录先确认。

## 来源/边界
- 内部编写；不涵盖内存级任意写（pwn 线）。
