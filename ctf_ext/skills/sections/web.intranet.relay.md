# web.intranet.relay

## 触发
- 多跳内网：已拿第一跳（SSRF/写入点/凭据）要横向打第二跳及以后，或题面给内网结构。

## 最小动作
1. 先立事实：arena_http 只达授权网段，原始 TCP 直连不可达；应用层中继是唯一路径。
2. 第一跳上做中继：中继脚本经写入点落盘（见 web.file_write）或注入已控服务，经它转发内网目标；tool=python_exec 生成。
3. SSRF 链：逐跳打内网 HTTP 服务读指纹；非 HTTP 服务在已控主机侧跑适配脚本，结果经 HTTP 带回。
4. 每跳登记 evidence：拓扑/凭据/服务；同密码逐跳试。

## 命中判据
- 经中继读到最终内网服务的唯一 flag{...}。
- 负判据：拓扑不可达或凭据缺失；写 ruled_out 记每跳路径。

## 何时换路
- 单点 SSRF 直达转 web.ssrf；写入点获取转 web.file_write。

## 踩坑
- 中继只传 HTTP：协议适配放已控主机侧。
- 末跳二进制服务：先落参数化 exploit 脚本（host/port/offset），每跳改参重跑，别手写。
- 每跳先确认指纹再打，别盲扫内网。

## 来源/边界
- 内部编写；不涵盖域渗透与权限维持。
