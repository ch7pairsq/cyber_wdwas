# web.xss

## 触发
- 页面回显用户输入（评论/搜索/昵称），或题面提示 bot/admin 会访问某 URL。
- 不适用：纯服务端漏洞、无反射点。

## 最小动作
1. tool=arena_http 探测回显点：提交探针串，确认落在 HTML 标签间、属性内还是 JS 字符串内。
2. tool=python_exec 按上下文闭合：标签间直接注入；属性内先逃逸引号；JS 字符串内先断字符串。DOM 型先读前端源码找 sink。
3. 有 bot：把含探针的 URL 提交给题面接口等待带出；无外带通道时用页面差异（长度/超时）侧信道确认执行。

## 命中判据
- 炸出 admin/flag 上下文，或服务端返回唯一 flag{...}。
- 负判据：CSP 拦截且无绕过点；写 ruled_out 并记录 CSP 策略。

## 何时换路
- 注入点在 SQL 层转 web.sqlinjection；模板回显转 web.ssti；侧信道深化转 web.xsleak。

## 踩坑
- 先读 CSP（meta/响应头）再构造，不要盲试载荷。
- 过滤常见时试大小写、编码、非常规标签；逐个验证再组合。

## 来源/边界
- 内部编写；不涵盖浏览器 0day 与 mxss。
