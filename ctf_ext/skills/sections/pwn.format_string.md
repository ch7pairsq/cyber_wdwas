# pwn.format_string

## 触发
- 交互程序把输入直接当 printf 格式串使用（回显 %x/%p 泄露栈数据，或 %s 引发崩溃）。

## 最小动作
1. tool=checksec 与 tool=disassemble 确认漏洞点、循环次数与输出函数。
2. tool=python_exec 用 pwntools 发 %6$p 系列枚举栈：定位输入自身偏移、目标地址（GOT/返回地址）与当前值。
3. 构造任意写：按字节用 %n 写入，先小改（返回地址低 2 字节或 GOT 项改后门函数），验证再全写。
4. 无执行边界时只做静态构造，把利用串与偏移写进 summary。

## 命中判据
- 静态：给出可复核的偏移与利用串，登记 evidence_id。
- 执行：边界内跑出唯一 flag{...}。
- 负判据：无格式串漏洞；写 ruled_out。

## 何时换路
- 主漏洞是栈溢出转 pwn.stack.recon；泄露齐 libc 转 pwn.ret2libc。

## 踩坑
- %n 写入先算目标字节序与对齐；32 位按 4 字节一组，64 位注意栈布局。
- 写坏一次后状态不可恢复，重开连接再试。

## 来源/边界
- 内部编写；不覆盖多次写链的完整自动化。
