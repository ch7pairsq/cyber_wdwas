# web.xsleak

## 触发
- 有 admin bot 机制（提交 URL 由机器人访问）加 XSS 过滤（DOMPurify 类），flag 在 bot 侧页面。

## 最小动作
1. tool=arena_http 摸 bot 提交接口与目标页（搜索/备注/页码等长度或状态可观测的点）。
2. 构造跨源探测：报错差异、搜索有无、帧数/历史长度、缓存时序，tool=python_exec 批量生成候选。
3. DOMPurify 常规 payload 被拦：试 mXSS、SVG/MathML 命名空间、属性继承变体，逐个记录拦截差异。
4. bot 禁外网时用题目允许的同源回传接口接收信号。

## 命中判据
- 侧信道逐位拼出完整唯一 flag{...}。
- 负判据：无回传通道且 bot 禁外网，数据带不出来；写 ruled_out。

## 何时换路
- bot 页面可存储注入直接读 DOM 转常规利用；接口直连数据库转 web.sqlinjection。

## 踩坑
- 每次只变一个量，避免侧信道噪声误判；警惕假 flag 诱导。
- 侧信道一轮只测一位，做好重试与一致性校验。

## 来源/边界
- 内部编写；不覆盖需要真实浏览器的深度利用。
